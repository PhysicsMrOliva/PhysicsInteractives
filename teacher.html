Connect to GitHub (one-time setup)

This lets “Save to GitHub” update availability.json in your repository directly. Your access key is kept only in this browser on this computer, never on the website.

How to make an access key (about 2 minutes)
  1. On github.com, click your profile picture, then Settings.
  2. At the bottom of the left menu, click Developer settings, then Personal access tokens → Fine-grained tokens, then Generate new token.
  3. Name it something like “Physics site teacher page” and set the expiration to the end of the school year.
  4. Under Repository access, choose Only select repositories and pick your website’s repository.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it, and paste it into the Access key box above.

The key only works on that one repository. If you ever think it was shared, delete it on GitHub and make a new one.
